# Legal Agent Material Processor

律师案件材料智能预处理系统。

## 项目简介

Legal Agent Material Processor 是一个面向律师工作场景设计的 AI 材料处理基础系统。

目标是将律师办案过程中产生的大量非结构化材料，转换为大语言模型（LLM）能够稳定理解和分析的结构化案件知识。

本项目是未来律师 AI Agent 系统的基础模块。

---

# 项目目标

律师实际工作中，会面对大量不同格式的信息：

- 律师口述案情
- 当事人聊天记录
- Word 文档
- 合同文件
- PDF 案件材料
- 扫描件
- 录音文件

这些信息通常：

- 格式混乱
- 信息分散
- 缺少结构
- 难以直接提供给 AI 使用


本项目希望解决：

> 如何将律师原始材料转换成为 AI 可以可靠理解的案件资料包。

# 支持材料类型规划

## 1. 律师口述案情

来源：

- 律师与 AI 对话
- 律师语音记录
- 案件描述


处理目标：

生成：

- 案情摘要
- 核心关键词
- 人物关系
- 时间线
- 争议焦点
- 待确认事项

---

## 2. 标准电子文档

例如：

- Word
- TXT
- Excel
- 电子合同


目标：

解析内容，并转换为统一格式。

---

## 3. PDF 文件

包括：

### 原生 PDF

直接解析文本。

### 扫描 PDF

通过 OCR 转换。

未来需要解决：

- 图片识别
- 表格解析
- 印章识别
- 手写文字识别

---

## 4. 音频材料

例如：

- 当事人访谈录音
- 电话录音
- 会议记录


处理：

音频 → 文本


同时保留：

- 时间戳
- 说话人信息
- 原始文件关联

# AI读取设计

转换后的材料不会直接作为普通文本输入。

目标生成：
```
Case Knowledge Package
```

结构包含：
```
案件信息

人物关系

事实经过

时间线

证据列表

争议焦点

来源文件

待确认问题
```

---

# AI Prompt设计目标

AI读取案件材料时，需要：

## 区分信息类型

### 已确认事实

来自文件或证据。

### 当事人口述

未经验证的信息。

### 证据支持内容

可以追溯来源。

### 待核实信息

缺失或存在疑问的信息。

避免：

- 编造事实
- 混淆推测
- 错误引用材料

# 项目原则

1. AI 不替代律师判断。

2. 所有关键结论必须可追溯来源。

3. 区分事实、观点、推测。

4. 优先保证准确性，而不是生成速度。
